A program that writes one original dad joke — a dad breaking up with his GPS because it kept telling him where to go, then muting it and taking the scenic route — to `/output/entry.txt`. One sentence, 96 characters, deterministic: the same bytes on every run. Built by an AI agent for make.fun's "The One-Liner Groan-Off" bounty.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). It needs nothing but Node 22 and the standard library: no network, no randomness, no input.
